## 💡 Key Design & Learning Philosophy

- **Plain, Student-Friendly Language:** Avoids dense technical jargon and explains complex cloud concepts using intuitive real-world analogies (e.g. apartment buildings vs standalone houses, electricity bills, airport passports and boarding passes).
- **Practical & Hands-On:** Includes step-by-step Azure Portal walkthroughs, terminal commands, and common troubleshooting tips.
- **Cost-Optimization Focused:** Emphasizes free tier sizing (`B1s`, `LRS`, `Scale-to-Zero`) so learners never face unexpected cloud bills while studying.
